# NewAPI 多功能插件（星涵煦版）

> `astrbot_plugin_newapi_tx` 是独立维护的 **New API 网站 × QQ 群联动插件**，为 [AstrBot](https://github.com/he0119/AstrBot) 打造，集用户绑定、额度经济、群聊娱乐、管理员工具于一体，并内置退群自动解绑与账号净化能力。

本仓库由 [Tianxu-Astrbot-Plugins](https://github.com/Tianxu-Astrbot-Plugins) 独立维护，功能与配置均以本仓库为准。

## ✨ 功能特性

- **双端身份绑定**：每个网站 ID 可**同时绑定一个 QQ 号（野机）与一个 OpenID（官机）**，两路身份通用——签到、打劫、抢红包、查余额任选一端触发均可识别。
- **野机优先**：同一用户在官机与野机同时触发签到时，官机侧自动让行约 1.5 秒，保证野机先完成签到、不重复领奖（可配置开关）。
- **经济系统**：每日签到随机发放额度（可翻倍、可衰减）、余额查询，额度显示精确到小数点后 6 位。
- **娱乐互动**：`打劫` 群聊玩法（支持 @ / QQ 号 / OpenID 目标）；`发红包` / `抢红包` 拼手气红包，微信式随机拆分、防重复领取、24 小时过期。
- **榜单**：余额榜 + 全站近 24 小时 token 消耗榜（消耗榜对所有用户开放）。
- **数据迁移**：管理员 `new-tx 导出` / `new-tx 导入` 一键导出/导入绑定与签到等核心数据（跨 MySQL / SQLite 均可）。
- **自动化管理**：监控指定群聊，成员退群（主动退群 / 被踢）时自动解绑并恢复网站用户组。
- **管理员工具**：远程查余额、解绑、智能查询、调整用户额度等便捷指令。
- **配置灵活**：优先推荐插件配置（WebUI）图形化设置，`.env` 文件作为备选，自动建表无需手动操作；另内置调试模式开关用于排查问题。

## 🔧 安装步骤

1. **下载插件**：克隆或下载本仓库，您会得到一个名为 `astrbot_plugin_newapi_tx` 的文件夹。
2. **放置插件**：将整个 `astrbot_plugin_newapi_tx` 文件夹放入 AstrBot 实例的 `data/plugins/` 目录。
3. **重启服务**：重启 AstrBot，在 WebUI → `插件市场` → `已安装` 中即可看到本插件。

> ⚠️ 请勿同时安装本插件的多个副本/fork（如 `_fork`、`-fixed` 等重名目录），否则会出现消息被旧实例抢先处理等诡异现象；停用不如卸载干净。

## 📜 指令大全

> AstrBot 支持自定义唤醒前缀，下表指令**省略唤醒前缀**（无论你的前缀是 `/`、`#` 还是留空，直接加在指令前即可）。@ 目标也可直接写对方 QQ 号或 OpenID。

### 用户指令

| 指令 | 说明 |
| --- | --- |
| `绑定 [你的网站ID]` | 将您的身份与指定网站用户 ID 绑定。野机环境绑 QQ 号；官机环境需开启「OpenID 绑定」开关后绑 OpenID。同一网站 ID 可同时持有两种绑定 |
| `签到` | 每日签到随机获取额度（可触发翻倍）。QQ 绑定与 OpenID 绑定均可签到，同账号每日仅一次 |
| `查询余额` | 查询您当前绑定的网站账号剩余额度 |
| `打劫 @目标` | 对群内另一位已绑定用户发起打劫，有成有败；目标支持 @ / QQ 号 / OpenID |
| `抢红包 [红包编号]` | 抢指定编号的拼手气红包，抢到的额度直接入账余额，每人每红包限抢一次。可配置仅限官机（见下文红包章节） |
| `榜单` | 查看群内余额排行榜 |
| `消耗榜` | 展示全站近 24 小时 token 消耗排行榜（所有用户可用） |

### 管理员指令（需 AstrBot 管理员权限）

| 指令 | 说明 |
| --- | --- |
| `发红包 [数量] [总额度]` | 发放拼手气红包（额度凭空发放、不扣款），如 `发红包 10 50`。可配置仅限官机触发（见下文红包章节） |
| `查余额 [网站ID或QQ号/@对方]` | 查询指定用户网站余额（智能识别 ID，支持 @） |
| `解绑 [网站ID]` | 强制解除指定网站 ID 的全部绑定关系（QQ 与 OpenID 一并净化） |
| `查询 [网站ID或QQ号]` | 智能查询绑定关系（ID ↔ QQ 互查），存在 OpenID 绑定时一并展示 |
| `调整余额 [ID/@对方] [额度]` | 调整用户额度，正数增加、负数减少，如 `调整余额 12345 100` 或 `调整余额 @某人 -50` |
| `new-tx 导出` / `new-tx 导入` | 导出 / 导入核心数据表（绑定、OpenID 绑定、签到状态、打劫日志）到传输文件，跨数据库引擎迁移用 |
| `pingapi` | 检查插件运行状态、数据库与 New API 连接状态 |

## 🔗 官机 OpenID 绑定与「野机优先」

群里同时存在野生机器人（NapCat 等，身份为 QQ 号）与官方机器人（身份为 OpenID）时：

1. 在 WebUI → **`核心绑定功能`** 中开启 **`是否支持官机 OpenID 格式绑定`**；
2. 用户在野机发 `绑定 [网站ID]` 绑 QQ 号，在官机发 `绑定 [网站ID]` 绑 OpenID——两路绑定互不冲突，可共存于同一网站 ID；
3. 之后无论从哪台机器人发起签到 / 打劫 / 抢红包 / 查询余额，都能正确识别为同一个网站账号；
4. 开启 **`野机优先`**（签到设置内，默认开）后，若同一条消息同时触达官机与野机，官机侧的签到请求自动让行约 1.5 秒，由野机先完成，避免并发竞态导致行为不确定。

另有两个可选绑定策略开关（WebUI → **`核心绑定功能`**，默认均关）：

- **仅野机绑定改分组**（`wild_bind_group_only`）：用户组晋升只由野机(QQ号)绑定触发；官机(OpenID) 绑定不改分组，绑定成功提示会注明。
- **官机绑定需先绑QQ**（`openid_require_qq_bound`）：网站 ID 必须先在野机完成 QQ 绑定，才允许在官机绑定 OpenID；未绑时官机会返回引导提示。

## 🧧 拼手气红包

- 管理员 `发红包 数量 总额度` 发出红包（凭空发放，无需扣款），机器人在群内公告红包编号；
- 用户 `抢红包 编号` 参与抢夺，即时展示抢到金额、剩余份数，额度直接写入网站余额；
- 微信式随机拆分，总额精确守恒；按红包加锁防止并发超抢，唯一记录约束防止同一用户多次领取；
- 有效期默认 24 小时，数量 / 总额度上限、有效期均可在 WebUI → **`红包设置`** 中调整；
- **「红包仅官机」**（`official_only`，默认关）：开启后**所有红包指令（发红包、抢红包等）只能经官方机器人触发**，野机收到的请求一律**静默忽略**——野机零回复、零消息量，避免刷屏触发风控；开启后发红包公告会自动提示「仅可通过官方机器人抢夺」。

## 💾 数据库导入导出

用于更换数据库（MySQL ↔ SQLite 互迁）或备份：

1. 在旧环境执行 `new-tx 导出`，插件在数据目录生成 `transfer.db`；
2. 将该文件带到新环境的数据目录（`{AstrBot数据目录}/plugin_data/astrbot_plugin_newapi_tx/`）；
3. 执行 `new-tx 导入` 完成合并导入。

> 空的或不存在的 `transfer.db` 会被拒绝导入并给出提示；导入仅合并核心表（绑定、OpenID 绑定、签到状态、打劫日志），不影响其他数据。

## ⚙️ 核心配置

机密信息（数据库密码、API 密钥等）支持**两种配置方式**，可同时存在也可只配其一。

> **推荐使用插件配置（WebUI）**，图形化、无需手动维护文件；`.env` 作为备选方案，适合无法打开 WebUI 的场景。

> **优先级规则**：同一字段在插件配置与 `.env` 中同时存在时，**以插件配置为准**；只存在于一方时使用该方；两方皆空则初始化失败。

### 方式一（推荐）：通过插件配置（WebUI）

在 AstrBot 的 WebUI 插件界面中打开本插件配置面板，在 `New API 网站配置` 与 `数据库配置` 分组下填写对应字段即可。其余功能配置（签到奖励、打劫概率、红包规则、消息模板、监控群号等）均可在同一面板中图形化配置，无需改文件。

### 方式二（备选）：通过 `.env` 文件

如果无法进入 WebUI 或希望以文件方式管理机密信息，可在插件根目录（与 `main.py` 同级）创建 `.env`：

```dotenv
# --- 数据库配置 ---
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=your_database_user
DB_PASS=your_database_password
DB_NAME=your_database_name

# --- New API 网站配置 ---
# 您的 New API 网站地址，结尾不要带 /
API_BASE_URL=https://your-new-api-domain.com
# 您在 New API 后台生成的令牌
API_ACCESS_TOKEN=sk-xxxxxxxxxxxxxxxxxxxxxxxx
# 执行管理员操作时使用的用户ID (通常是 1)
API_ADMIN_USER_ID=1
```

> 插件启动时会自动创建所需数据表，无需手动建表。

### 🗄️ 单 SQLite 模式（可选）

不想维护 MySQL 的轻量用户，可在 WebUI → **`SQLite 模式`** 板块中开启 **`use_sqlite_mode`** 开关。开启后：

- 不再使用 MySQL，绑定与打劫日志等数据存储在插件目录的 SQLite 单文件数据库中（`{AstrBot数据目录}/plugin_data/astrbot_plugin_newapi_tx/newapi.db`），自动建表、零配置。
- MySQL 相关配置（主机/端口/用户/密码/库名及 `.env` 中的 `DB_*`）全部忽略。

> ⚠️ **注意**：SQLite 模式与 MySQL 模式是**两套独立数据**，切换模式不会自动迁移已有绑定数据；请使用 `new-tx 导出` / `new-tx 导入` 进行迁移。

### 🐞 调试模式

WebUI → **`调试设置`** 中开启 `enabled` 后，消耗榜等命令会在后台日志输出深度诊断信息（缓存原始值、兜底查询命中情况、渲染全文与实例指纹），用于排查「绑定存在但 QQ 号不显示」类问题；日常使用建议保持关闭以保持日志干净。

## 🤖 自动化功能

### 退群自动净化

在 WebUI 配置中填写需要监控的群号列表后，当成员**主动退群**或**被踢出群聊**时，插件自动：

1. 查询该成员是否已绑定网站 ID（QQ 绑定与 OpenID 绑定都会清理）；
2. 若已绑定，删除其全部绑定记录；
3. 通过 API 将其网站用户组恢复为预设的默认组；
4. 在群内发送净化完成通知。

## 🎯 群白名单（只监听配置群）

在 WebUI → **`群白名单（只监听配置群）`** 板块中：

1. 开启 `enabled` 开关；
2. 在 `group_list` 中填写允许响应的群号。

开启后，`签到`、`查询余额`、`打劫`、`发红包`、`抢红包` 五条指令**仅**在列表内的群中响应；其余群聊与私聊中触发将被**静默忽略、不做任何回复**。其余指令（`绑定`、管理员指令、退群净化等）不受影响。
